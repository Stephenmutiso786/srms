# SRMS VirtualBox VM

If you want a full machine image, package SRMS inside a VirtualBox VM.

## Why use a VM

- Exact same environment every time
- Easy to snapshot and restore
- Good when staff need a prebuilt Windows or Linux desktop

## Suggested approach

- Create a VM with Ubuntu or Windows
- Install PHP, Apache, and MySQL inside the VM
- Place SRMS in the VM
- Take a snapshot after the install works
- Clone or export the VM for transfer
