# Windows SRMS

Use the Windows installer for staff laptops.

## Built pieces

- `windows/SRMS.iss`
- `windows/runtime/bootstrap.ps1`
- `windows/runtime/Backup-SRMS.ps1`
- `windows/runtime/Start-SRMS.bat`

## Result

The build produces a `Setup.exe` installer when compiled in Inno Setup on Windows.
